Match type assignment

Each edge's match_type is determined by checking sources in priority order. The pipeline uses the first source that has a SKOS match assertion for the xref and stops:

  1. MONDO — OWL SKOS predicates (exactMatch, broadMatch, etc.)
  2. GARD — GARD-owned GARD IDs are treated as curated exact xrefs
  3. Orphanet — mapping relation attributes
  4. MedGen — concept relationship types
  5. DOID — OWL SKOS predicates

If none of these sources asserts a match type for a given xref, the edge is labeled unclassified. This commonly happens for:

  • Stale GARD references from non-GARD sources — retained for review and obsolete-source reporting
  • NodeNorm-only xrefs (SNOMEDCT, ICD10, MESH, etc.) — only classified if MONDO or DOID also asserts that specific xref
  • OMIM / OMIMPS — deferred to "unclassified" by default

mapping_confidence scores

exact1.0
broad0.4
narrow0.4
unclassified0.3
related0.2

Penalty: −0.2 if sources disagree (contested), −0.1 if match type was structurally inferred rather than source-asserted.

label_confidence

Compares the concept's standard_name against the xref's preferred_label and all known synonyms. Uses three algorithms and takes the best score:

  • SequenceMatcher — character-level ratio after Unicode normalization
  • Containment — token overlap / min(token count) × 0.98
  • Jaccard — token overlap / union of tokens

Labels are sourced from local transforms (MONDO, DOID, OMIM, Orphanet, MedGen, GARD), NodeNorm pre-computed labels (UMLS, MESH, SNOMEDCT, NCIT, ICD10, etc.), public OBO downloads (EFO, NCIT, HP), and UMLS REST API lookups.

source_support

Counts how many independent sources (mondo, doid, medgen, orphanet, omim, gard, nodenorm) assert this specific xref ID in the harmonization file. Normalized to 0–1:

0 sources0.00
1 source0.50
2 sources0.75
3 sources0.88
4+ sources1.00

structural_confidence

Minimum of two graph-level heuristics. Not included in the composite xref_confidence score (weight = 0), but still computed and displayed for reference.

  • Cardinality score — one-to-one = 1.0, one-to-many = 0.6, many-to-one = 0.5, complex = 0.3
  • Proxy sharing — how many concepts share this xref ID: 1 = 1.0, 2–3 = 0.7, 4+ = 0.4
