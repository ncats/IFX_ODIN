Drug Harmonizer API

GET/drug-id-qa/api/stats
Release stats, source coverage, identity-key tiers, relationship counts, and source catalog.
GET/drug-id-qa/api/search?q=aspirin
Search IFXDrug IDs, names, synonyms, UNII, ChEMBL, ChEBI, PubChem CID, DrugCentral, RxCUI, CAS, and InChIKey.
GET/drug-id-qa/api/graph?ids=aspirin
Graph-ready identity xrefs, product context, and drug-target evidence.
POST/drug-id-qa/api/resolve
Batch resolve + enrich drug queries against local graph and live APIs (NCATS Resolver, Pharos, Inxight, openFDA, ChEBI).
GET/drug-id-qa/api/resolve-quick?q=aspirin|ibuprofen
Quick local-only resolution (no enrichment, instant response). Pipe-separated queries.
