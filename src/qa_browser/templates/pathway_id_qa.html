Pathway Harmonizer API

GET/pathway-id-qa/api/stats
Release stats, source counts, similarity distribution, and source catalog.
GET/pathway-id-qa/api/search?q=cell+cycle&source=Reactome
Search IFXPathway IDs, pathway names, Reactome/WikiPathway/PANTHER/BioPlanet IDs.
GET/pathway-id-qa/api/graph?ids=IFXPathway:2H5EXUN
Graph-ready pathway and gene-member neighborhood.
GET/pathway-id-qa/download-filtered?format=tsv
Download filtered pathway data as TSV or CSV.
GET/pathway-id-qa/api/versions
List available versioned pathway datasets.
GET/pathway-id-qa/api/version-diff?from_version=0.1.0&to_version=0.2.0
Compute delta between two versioned pathway datasets.
GET/pathway-id-qa/api/review-queue?status=open&scenario=singleton_pathway
Paginated QC review queue with scenario, severity, and status filters.
GET/pathway-id-qa/download-review-template
Download filtered review data as a TSV intake template.
POST/pathway-id-qa/api/review-decisions
Save review decisions to the pathway review-intake TSV.
